How to give readers a URL

  1. Use Export story to download your project JSON.
  2. In your GitHub repository, create a folder named stories at the site root if it does not already exist.
  3. Upload the exported file as your-story.json into that folder.
  4. Wait for Netlify to finish deploying.
  5. Share the URL shown below.
https://ceeqwinn.netlify.app/read.html?story=emerald-inheritance-demo

The public Reader expects the JSON file at stories/SLUG.json. Publishing is not automatic: the exported file must be uploaded and deployed. This URL works after the matching Reader files and story JSON are online.
